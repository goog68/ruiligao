# 一句话设计 · 3D & CAD 出图 + 图纸查看器

瑞利高展示科技（亚克力精工定制）内部设计辅助工具：输入一句话，自动生成 3D 方案图与 CAD 三视图工程图；
配一个图纸查看器，能直接打开 DXF / SVG / PDF / 图片，分图层看、量尺寸、导出。

两个页面，都可离线双击运行：

| 文件 | 作用 |
|---|---|
| `index.html` | 设计出图：一句话 / 一张图 → 3D 方案图 + CAD 工程图 → 导出 DXF/SVG/PNG |
| `viewer.html` | 图纸查看：DXF 分图层渲染、平移缩放、导出 PNG；SVG/PDF/图片直接看 |
| `model3d.html` | **3D 全角度查看**：从真实 DXF 自动重建旋转体，鼠标拖拽 360° 旋转、缩放、平移 |

## 一句话能做什么

```
三层亚克力展示架，宽600，深400，高1500
亚克力展柜 900×500×1800，两层，板厚20
亚克力展示台，宽1200，深600，高900，板厚25
亚克力陈列盒 400×300×250，分四格
亚克力灯箱，宽800，高600，深120，板厚15
```

识别维度：类型、宽 W、深 D、高 H、层数、板厚 t。支持 `600×400×1500` 三连写法，支持“宽0.6米”这类单位写法，支持“三层 / 3 层”中文数字。

## 丢一张图也能出图

左栏顶部是上传区，支持**点击选择 / 拖拽 / Ctrl+V 粘贴**三种方式把产品图丢进去。

单张图没有深度信息，推不出绝对尺寸，所以只反推三样东西：

| 反推项 | 做法 |
|---|---|
| 结构类型 | 按轮廓宽高比 + 前景填充率判断（宽扁→台，实心→柜，镂空→架） |
| 高宽比 | 前景包围盒 W/H，作为宽度基准 |
| 层数 | 逐行统计前景宽度，层板处形成横向通长峰值，数峰值得层数（减掉底座那条） |

然后「你给高度、它算宽度」：改**高 H** 时，宽 W 会自动按图片比例跟着走，深 D 按 0.62W 估。

这是工程上唯一靠谱的用法——比例来自图，绝对尺寸来自你的基准值。图不能直接变成精确 3D 模型，任何声称能做到的都是猜。

## 输出什么

| 区域 | 内容 |
|---|---|
| 左栏 | 识别结果 + 可手工微调的参数（改完实时重算） |
| 中栏 | 3D 方案图，拖拽旋转、滚轮缩放、可导出 PNG |
| 右栏 | CAD 三视图（正视图 / 侧视图 / 俯视图）+ 尺寸标注 + 标题栏，可导出 SVG、可直接打印 |

## 支持的结构类型

- 亚克力展示架（`rack`）：底座 + 双侧板 + 背板 + 多层搁板
- 亚克力展柜（`cabinet`）：底座 + 四立柱 + 顶板 + 三面玻璃 + 内层板
- 亚克力展示台（`table`）：台面 + 四腿 + 下隔板
- 亚克力陈列盒（`box`）：盒体 + 分格
- 亚克力灯箱（`lightbox`）：铝框 + 发光面 + 背板
- 亚克力槽体（`tank`）：矩形开口槽，底板 + 四壁 + 沿口翻边 + 竖向加强筋
- **亚克力生长槽（`vessel`，圆柱罐体）**：见下节

## 圆柱生长槽（罐体）—— 按真实图纸建的结构

参数含义与其它类型不同，面板标签会自动切换：

| 输入框 | 含义 | 图纸对应 |
|---|---|---|
| 筒体外径 Φ | 罐体外径，内径自动 = 外径 − 2×壁厚 | Φ1090 / 内 Φ1050 |
| 法兰外径 Φ | 顶部法兰外径，内径取筒体内径 | Φ1250 / 内 Φ1050 |
| 总高 H | 底到法兰顶 | 1850 |
| 三角支撑数 | 法兰下加强筋数量 | 12 件 |
| 壁厚 t | 筒体板厚 | 20 |

自动派生的结构：24×Φ14 螺栓孔（螺栓圆 = (法兰外径+内径)/2 = Φ1150）、
上部直筒 → 锥段过渡 → 底部裙座（厚 30）、斜支管与回流管（Φ50）。
CAD 图按“正视图 + 俯视图（去盖）+ 盖板俯视图”三块排版，圆用真实 CIRCLE 实体输出，进 CAD 可量可编辑。

一句话写法：

```
生长槽 外径1090 法兰1250 高1850 壁厚20 12个支撑
```

## 3D 全角度查看器（model3d.html）

把「做成 3D、上下左右都能看」这件事真正落地：**从真实 DXF 图纸自动重建 3D 模型**，而不是手工填参数。

### 它是怎么工作的

1. 解析 DXF，在「中心线」图层里找**旋转轴**（最长的竖直线）
2. 在「粗实线」图层里提取**旋转轮廓**——每条线段投影成「高度 → 半径」
3. 绕轴旋转生成 3D 网格（Lathe），用 Three.js 渲染成半透明亚克力材质

### 操作

| 操作 | 动作 |
|---|---|
| 旋转（上下左右任意角度） | 鼠标**左键拖拽** |
| 缩放 | **滚轮** |
| 平移 | 鼠标**右键拖拽** |
| 自动旋转展示 | 点「▶ 自动旋转」按钮 |
| 标准视角 | 侧栏一键切「正视 / 俯视 / 侧视 / 复位」 |
| 触屏 | 单指旋转、双指缩放平移 |

左侧面板可调：透明度、实体着色开关、边缘线框、坐标轴、半透明透视（看内部结构）。

### 默认模型

启动即加载「生长槽缩短40厘米」真实图纸重建的模型，参数自动识别：总高 1850、最大直径 Φ1250、裙座→锥段→筒体→法兰的完整轮廓。

### 导入其它 DXF

点「拖入 / 选择 DXF 图纸重建」，任何含「粗实线 + 中心线」图层的 DXF 都能自动重建（适合各种旋转体：罐、筒、瓶、轴、轮等）。

技术栈：Three.js r128 + OrbitControls，已本地化（`three.min.js`、`OrbitControls.js`），**完全离线可用**。

## 六面视图 + 尺寸标注 + 测量 + 改尺寸 + 打印

点 3D 查看器里的「📐 六面视图」按钮，进入工程图六视图模式：

| 功能 | 说明 |
|---|---|
| **六面视图** | 上/下/前/后/左/右 六个方向的正交投影，按工程图 3×2 排布 |
| **标注尺寸** | 自动在视图上画红色尺寸线：总高、法兰直径 Φ、各段直径 |
| **量尺寸** | 点「📏 量尺寸」，在任一视图点两个位置，实时显示 3D 距离（mm） |
| **改尺寸** | 点「✏️ 改尺寸」，改总高/法兰Φ/筒体Φ/裙座Φ，点「应用」模型实时重建 |
| **打印/导出** | 点「🖨 打印/导出」，自动排成 A4 横向图纸（含图框、标题、尺寸），直接打印或存 PDF |

### 复杂图纸能不能做？

当前自动重建**针对旋转体**（罐/筒/瓶/轴/轮/法兰盘等绕轴旋转的形体）最可靠。
非旋转体（异形板、带方孔/槽的结构、多部件装配）目前需要更完整的 DXF 3D 实体解析，
属于下一步要单独做的工作。你有这类图纸可以先发我，我评估后给你方案。

## 图纸查看器（viewer.html）

把文件拖进窗口即可，也可以在「导出 DXF」旁边点 **看图纸** 打开。

| 格式 | 处理方式 |
|---|---|
| **DXF** | 自写解析器，支持 LINE / CIRCLE / ARC / LWPOLYLINE / POLYLINE / TEXT / MTEXT / SOLID / POINT，递归展开 INSERT 与标注块；左侧按图层开关显隐，可导出 PNG |
| SVG / PNG / JPG / WEBP / BMP | 图像方式查看，平移缩放 |
| PDF | 用浏览器内置阅读器打开 |
| **DWG** | 压缩二进制，浏览器读不了，需先转 DXF（见下） |

## DWG 怎么读（本机已装好工具）

工具在 `D:/瑞利高设计工具`（约 60 MB，含 LibreDWG 0.14 + Python 图纸库 ezdxf）。
不想要了这个文件夹整个删掉即可，C 盘无残留。

转换：把 `.dwg` 拖到 `D:/瑞利高设计工具/把DWG转成DXF.bat` 上，同目录 `work\` 里出同名 `.dxf`，
再把 DXF 拖进查看器。中文路径、中文文件名都已验证可用。

技术链路：DWG → (LibreDWG `dwg2dxf`) → DXF → (查看器解析) → 分图层矢量渲染。

## 怎么跑

零依赖、零构建，双击 `index.html` 用浏览器打开即可。建议 Chrome / Edge。

想用本地服务打开（推荐，导出文件更稳）：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080`。

## 导出 DXF，用桌面 CAD 打开

右上「CAD 工程图」卡片里有 **导出 DXF**。文件按 **1:1 真实毫米**绘制，AutoCAD / 中望CAD / 浩辰 / LibreCAD 双击即可打开，量出来的尺寸就是实际尺寸。

- 格式：DXF R12（AC1009），兼容性最好的版本
- 图层：`OUTLINE` 轮廓 / `THIN` 细线 / `GLASS` 玻璃 / `HIDDEN` 虚线 / `DIM` 尺寸 / `TEXT` 文字 / `FRAME` 图框
- 单位：`$INSUNITS = 4`（毫米）
- 投影：第一角法（俯视图在主视图下方、侧视图在右侧，GB 制图习惯）
- 文字：DXF 内部只用英文（`FRONT VIEW` / `SHELF` / `RUILIGAO DISPLAY TECH`），避免中文在 CAD 里变乱码；屏幕上的 SVG 和打印保留中文

打开前先装 CAD：中望CAD 个人版（免费）、浩辰、AutoCAD、LibreCAD（开源免费）都行。

## 技术说明

- 单文件 `index.html`，无任何第三方库、无需联网（离线可用）
- 3D：自研轻量渲染器（Canvas 2D + 透视投影 + 背面剔除 + 画家算法排序）
- CAD：参数化生成 SVG（三视图、尺寸线、标题栏、图框），纯矢量，可无损缩放打印
- 尺寸单位统一 mm，模型以底面为 y=0、原点在底面中心

## 已验证

用真实图纸跑通（`生长槽缩短40厘米.dwg`，AC1021 / AutoCAD 2007）：

- LibreDWG 转换 → 659 KB DXF，703 个实体、11 个图层
- 查看器解析出的图幅 14125 × 6276 mm，与 ezdxf 独立计算完全一致
- 中文标题、24-Φ14 孔位、尺寸标注、零件明细全部正确渲染
- 导出的 DXF 经 ezdxf 复核：56 个 CIRCLE、图幅 1250 法兰、纯 ASCII 文字、7 个图层
